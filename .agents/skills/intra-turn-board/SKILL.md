name: intra-turn-board
description: ローカルの無限キャンバスで付箋に依頼を書き、AI が書き出した文の空欄を埋めて続きを作る。Claude Code と Codex のどちらからでも、呼び出し元のセッションを fork して返事を書く。ボードを起動して一緒に考えたいときに使う。
---

このファイルと同じディレクトリの server.mjs を、呼び出し元の作業ディレクトリから Node.js 22 以降で、バックグラウンドのプロセスとして起動する。ホストとセッション ID は起動引数で渡す。

- Claude Code：`node <このディレクトリ>/server.mjs --host claude --session ${CLAUDE_SESSION_ID}` を、Bash の `run_in_background` で起動する。
- Codex：`node <このディレクトリ>/server.mjs --host codex --session "$CODEX_THREAD_ID"` を起動する。引数を省略しても、CODEX_THREAD_ID があれば codex として起動する。

サーバーの標準出力の最初の行に出るトークン付き URL をそのままユーザーに伝え、プロセスを起動したままターンを終える。終了を頼まれたらそのプロセスを停止する。

付箋に依頼を書くと、入力中に前提を下線と候補で示す。名詞は、ページを開いたときに jsDelivr から読み込む Kuromoji の辞書（約18MB）で拾う（URL、パス、識別子は除く。読み込めなければ、下線は引かない）。拾った名詞のどれに下線を引くかは、サーバーの環境に TYPESAFE_API_KEY があれば Jev（TypeSafe System One）が判定し（envchain などで渡して起動する）、無ければ、またその答えが届くまでは、ローカルの規則が選ぶ。Jev には、節が閉じたとき（句読点か改行）と、入力の手が止まったときに聞き、値の高い上位3語（0.3 以上）に下線を引く。会話の未決の論点に当たる語は、値に関わらず引く。「送る」を押すと呼び出し元のセッションを fork して返事の書き出しが届き、文中の空欄を候補または自由入力で埋めると続きが書かれる。続きのあとで空欄を選び直すと、そこから書き直す。失敗したときはカードの下の「もう一度」で、その段階だけやり直せる。返事の一節を選ぶと、そこについて付箋で聞ける。背景をドラッグして移動し、付箋とカードは上端をつかんで動かせる。ボードはページを閉じるか再読み込みすると消える。

サーバーの標準出力には、モデルを呼ぶたびに `{stage, host, ms, cost_usd, usage}` の1行が出る。モデルと effort は呼び出し元と同じで、変えるときだけ環境変数 INTRA_TURN_MODEL と INTRA_TURN_EFFORT で指定する。起動時には会話の発話から未決の論点と決まったことの在庫を作り、`stage` が `inventory` の1行を同じように出す。Jev の判定は、呼ぶたびに `{stage: 'judge', ms, input_tokens, n}` の1行を出す。board.html をファイルとして直接開くと、モデルを呼ばない見本の台本と、用意した語の辞書（LEXICON）で動く。サーバーから開いたボードは、この辞書を使わない。
